Welcome, user! 🎉

You're authenticated. Your session is secured with httpOnly cookies & CSRF tokens.

🔒
Password Storage
✓ Active

Your password is hashed with bcrypt (cost factor 12). The plaintext is never stored or logged.

🛡️
CSRF Protection
✓ Active

Every request carries a CSRF token validated server-side. Forged cross-site requests are rejected with 403.

⚠️
Rate Limiting
✓ Active

Auth endpoints allow 20 requests / 15 min per IP. Excess requests are blocked with HTTP 429.

🔑
Session Security
✓ Active

Session cookie uses httpOnly + sameSite=strict. Session ID is regenerated on login to prevent fixation.

🚫
Injection Prevention
✓ Active

All DB queries use parameterized patterns — user input never touches the query string. XSS blocked by CSP + output escaping.

🔐
Account Lockout
✓ Active

5 failed login attempts lock the account for 15 minutes. Errors are intentionally vague to prevent user enumeration.
